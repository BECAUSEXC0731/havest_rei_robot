## 2. 详细步骤

### 2.1 停止建图

在**建图终端**按 `Ctrl+C` 停止 `cartographer.launch.py`（或 `fox_slam.launch.py`），确认所有建图相关节点退出。

### 2.2 启动导航

```bash
export REI_ROBOT=fox_three

# 启动导航（含机器人模型/底盘/雷达/地图/lidar_loc 定位/规划/控制/RViz）
ros2 launch fox_navigation_ros2 fox_navigation.launch.py
```

> 导航默认加载地图：`/home/ubuntu/ros2fox/maps/test_map.yaml`（已在 `nav2_params.yaml` 中配置）。

### 2.3 检查启动是否正常（另开终端）

```bash
# ① 检查关键节点是否在线
ros2 node list
# 应包含：robot_state_publisher / rei_base / ydlidar_ros2_driver_node /
#         map_server / lidar_loc / planner_server / controller_server /
#         bt_navigator / behavior_server / lifecycle_manager_navigation

# ② 检查地图是否加载（应看到栅格地图数据）
ros2 topic echo /map --once | head -5

# ③ 检查 TF 树是否完整
ros2 run tf2_ros tf2_echo map base_footprint     # 应能持续输出变换
ros2 run tf2_ros tf2_echo base_footprint front_lidar_link

# ④ 检查激光是否正常
ros2 topic echo /scan --once | head -5
```

### 2.4 设置初始位姿

在 **RViz** 中：
1. 点击工具栏 **`2D Pose Estimate`**
2. 在地图上机器人实际位置处**点击并拖拽**出朝向箭头
3. 确认 RViz 中机器人模型（TF）贴合到地图上的实际位置（lidar_loc 无粒子云）

> 也可命令行发布：
> ```bash
> ros2 topic pub /initialpose geometry_msgs/msg/PoseWithCovarianceStamped \
>   "{header: {frame_id: 'map'}, pose: {pose: {position: {x: 0.0, y: 0.0}, orientation: {w: 1.0}}}}" --once
> ```

### 2.5 发布导航目标

在 **RViz** 中点击工具栏 **`2D Goal Pose`**，在地图上点击目标点并拖拽出朝向。

或用命令行发布目标：

```bash
# 让机器人走到 map 坐标 (1.0, 0.0)，朝向 +X
ros2 action send_goal /navigate_to_pose nav2_msgs/action/NavigateToPose \
  "{pose: {header: {frame_id: 'map'}, pose: {position: {x: 1.0, y: 0.0, z: 0.0}, orientation: {w: 1.0}}}}"
```

### 2.6 观察行为

- RViz 中应出现：全局路径（绿色）+ 局部轨迹（DWA 采样）
- 机器人应平滑移动，到达目标后停止（到位容差 xy=0.05m）
- 若途中遇障碍，应能重新规划绕行

## 3. 常见问题排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| `map_server` 报找不到地图 | yaml_filename 路径不对 | 检查 `nav2_params.yaml` 中 `yaml_filename` 是否为绝对路径 |
| TF 报 `front_lidar_link` 不存在 | 雷达 frame_id 与 URDF 不一致 | 确认雷达用 `fox_lidar_params.yaml`（frame=front_lidar_link） |
| `/cmd_vel` 无输出 | 建图未停，或 lidar_loc 匹配失败（无 map→odom） | 停建图；重新设置初始位姿 |
| lidar_loc 定位不贴合/跟丢 | 初始位姿不准，或处于空旷无墙区 | 重新 `2D Pose Estimate`；沿墙行走 |
| 机器人原地打转/抖动 | 局部代价地图障碍误判 | 检查雷达安装朝向（`inverted` 参数） |
| `bt_navigator` 报错 | 地图 frame 与定位不一致 | 检查 TF 树 `map→odom` 是否由 lidar_loc 发布 |
| 雷达/底盘串口打不开 | 与建图进程端口冲突 | 确认建图已完全停止 |
